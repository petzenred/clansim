# ClanSimulator
ClanSimulator (aka ClanSim) is an overhaul of the warrior cat game ClanGenerator (aka ClanGen) built using Python and 
Pygame.

### Description
The main idea behind this overhaul is to increase the difficulty of the game after the point where you have enough cats 
to ensure survival. This is accomplished in two main ways:

1) **Raise the stakes** in the form of new kinds of consequences for negative event outcomes, beyond cats getting 
hurt and dying.
2) **Increase gameplay complexity** by overhauling patrols and the relationship system, between cats in the same Clan 
and between different Clans.
